About

About Selixor Systems

Pulse. A mmWave node. A signed class.

Selixor Systems manufactures Pulse: a mmWave radio node that classifies presence and motion state inside a nominated volume — hull, corridor, border, airframe — without forming an image. Inference executes on the device. The delivered artifact is a signed operational class written into the duty tree or the C2 bus the operator already runs. The waveform does not leave the node. Pulse does not assume command.

Corporate seat: Torrey Pines, San Diego. The radio stack was first engineered in Mexico City.

Mission

Give command a signed, on-node state for volumes that remain outside electro-optical coverage. Control of a volume is not the same as knowledge of its state. A compartment is held when occupancy can be reported without standing up an image chain, and when that report can enter the graph the command already treats as authoritative.

Why

A blind volume is a command failure. Hulls, corridors, perimeters, and airframes routinely sit outside usable EO line of sight. Cameras cannot be emplaced, cannot see through the structure, or must not produce a record of a person. In those compartments the operator either runs the volume with no class, or imports a surveillance stack the chain did not ask for. Pulse exists so that occupied, still, unmatched, fallen, and vital can be decided on the node and seated in duty or C2. Not as a feed. As a signed event.

What we resolve

Volumes held without a reportable state. Presence that must be classified without an image product and without identity. Alerting that must enter an existing duty tree or C2 bus rather than open a parallel display chain. Sensing that must keep the raw waveform resident on the node.

How

A Pulse node holds continuous mmWave dwell on the nominated volume. Range-Doppler maps and micro-Doppler returns are scored on-device against a pinned model. The node emits an operational class and a calibrated confidence — not a reconstruction of a body. An optional voice challenge may be parameterized by the operator. Audio is not retained. Classification continues if challenge is off. The event is signed (Ed25519) and written to the duty tree or C2 already fielded. The same node mounts on a mast, in a doorway, or on an airframe.

Security protocol

The event is an operational object, not a waveform. Pulse signs that object with Ed25519 (RFC 8032): 32-byte public key, 64-byte signature. Verification is performed by the duty tree or C2 bus already fielded. A failed check discards the event. The raw return never leaves the node and is not a signed export. Ed25519 authenticates origin and integrity of the class; it does not encrypt the payload and it does not confer command authority.

Signed event

The node emits a class, a calibrated confidence, node identity, volume identity, model version, and time. That object is signed on-device. The duty tree verifies the signature against the node public key already held in inventory. If the check fails, the event is not seated. Pulse writes an object. It does not issue an order.
